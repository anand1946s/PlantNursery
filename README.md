# 🌿 PlantNursery — Simple Plant Shop Frontend

**PlantNursery** is a minimal web-frontend for a plant-shop / nursery catalog — enabling users to browse a list of plants, add items to a cart, and simulate a billing/order-placement flow.  
It was created as a college group-project (4 members) to build a basic e-shop frontend without using heavy frameworks — just HTML, CSS and vanilla JavaScript.

---

## ⚙️ Features

- Browse plants by category  
- Add items to cart  
- View cart contents and total bill  
- Simple static UI (no backend) — acts as a demo frontend shop  

---

## 🧪 Tech Stack

- **HTML5** — for page structure  
- **CSS3** — for styling and layout  
- **JavaScript (Vanilla)** — for basic interactivity (cart, billing simulation)  
- Pure client-side: No backend / database.  

---

## 🔄 How to run / Demo

1. Clone/download the repository  
2. Open `main.html` (or `index.html`, whichever is the root file) in your browser  
3. Start browsing, add items to cart, view bill  

No server required — runs purely on client side.
